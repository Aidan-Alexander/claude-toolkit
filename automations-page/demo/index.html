Keeping this page current

The page doesn’t check anything itself. It shows what Claude last wrote here. To update the statuses, ask Claude Code to check my automations. It looks at the Claude app’s Scheduled tasks and your claude.ai routines, asks you about anything elsewhere, and tells you what needs a look.

If you said yes to it at setup, Claude also updates this list whenever it sets up, changes or removes an automation for you. You can always ask it to add something it didn’t set up, such as a Zapier zap.
